Run DSATUR allocation

Select a timetable date. Existing results are preserved unless you explicitly confirm replacement.

01

DSATUR graph coloring

Classes are vertices; overlaps create edges. Highest saturation and degree guide each next assignment. Greedy coloring is useful, but does not guarantee an optimal timetable.

02

Segment tree availability

Each room has a 1,440-minute occupancy tree. Half-open ranges [start, end) make adjacent classes non-overlapping; range query and update are O(log N).

03

Flow estimate & baseline

Edmonds–Karp BFS and First-Fit compare modeled assignments. Flow shares capacity for identical room/time slots; partial overlaps across different boundaries are not encoded, so it is an estimate only.
